🕹️ How to play with Byte

Byte is a tiny robot made of SVG and JavaScript. It lives on Utsha's GitHub profile and loves attention. Here is everything it can do.

🖱️ Mouse & touch

  • Hover: Byte smiles, blushes and follows your cursor with its eyes.
  • Click: a random surprise every time.
  • Double-click: a backflip.
  • Drag: carry Byte around. Throw it fast to make it spin.
  • Rub the head side to side to pet it.

🎯 Hidden buttons

  • Antenna: lightning and a bright idea.
  • Chest screen: cycles heartbeat, CPU graph, clock, smiley, code and music.
  • 12 clicks, or clicking very fast, makes Byte dizzy.
  • Every 30 clicks it overheats and reboots.

⌨️ Keyboard

  • Arrow keys fly Byte around. Space makes it jump.
  • Type hello, dance, joke, love, sleep or utsha anywhere on the page.
  • Type disco, or the Konami code (↑ ↑ ↓ ↓ ← → ← → B A), for a party.

💬 Questions

  • Tap any question in Ask Byte about Utsha: about Utsha, work and skills, GitHub stats.
  • Project spotlight has a button for every public repository.
  • Answers use public data only and refresh automatically every few hours.

⚡ Energy & 💖 happiness

  • Every action uses energy. At zero, Byte asks to be charged with 🔋.
  • Happiness grows with petting, dancing and love, and slowly fades when Byte is ignored.
  • Leave Byte alone for 15 seconds and it falls asleep.
